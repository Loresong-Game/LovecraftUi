THE DROWNED DEPTHS

A game that lives on its own page — the interface is a guest here

Host controls — plain DOM, outside the library

THE STAGE ABOVE

The framed panel is the game's viewport: the site's own canvas paints the water, and the interface boots into the same element as a guest. The page around it keeps every native behavior — it scrolls, it selects, it owns the wheel everywhere the interface has no scrolling surface of its own.

Unmake tears the interface down; Call it back reboots it. The water never stops painting either way — the host page answers to nobody.
